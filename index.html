Documents déjà ouverts (disponibles hors ligne)

Appui long sur le texte pour sélectionner un passage, puis « Commenter ce passage ». Glisser à gauche ou à droite pour tourner les pages.

Dictée : bouton 🎤, ou le micro du clavier (Samsung ou Gboard). Pour dicter sans réseau, installer le français hors ligne dans le clavier (Gboard : Paramètres › Saisie vocale › Reconnaissance vocale hors connexion). Le bouton ⏺ Mémo enregistre votre voix et la joint au commentaire : il marche toujours hors ligne.

Tout reste dans le téléphone. « Exporter… › Partager » envoie les commentaires (JSON, Markdown, LaTeX, mémos) où vous voulez, par exemple dans la Dropbox ; le lecteur du poste relit le JSON.
